# Poppy's Coffee & Juice

A custom website concept for Poppy's Coffee & Juice in downtown Edmonton, built with Next.js and actual business photography supplied for the demo.

## Development

```bash
npm install
npm run dev
```

The site deliberately does not list unconfirmed opening hours, menu items, prices, or an opening date. Add those only after Poppy's confirms them.

## Content and assets

- Business address: 10621 100 Avenue NW, Edmonton, Alberta.
- Instagram: https://www.instagram.com/poppys_yeg/
- Photography: supplied reference images of the actual Poppy's space and Instagram grid, rather than generated cafe imagery.

This is a design demo, not Poppy's official website. Confirm photo usage, brand approval, exact menu, opening date, and hours before client launch.
